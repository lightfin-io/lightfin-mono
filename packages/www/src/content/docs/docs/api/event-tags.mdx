Event tags are house-shaped badges along the bottom of the price pane. Set a
symbol for any event you want to flag, such as **E** for earnings or **D** for
dividends. Clicking a tag calls `onSelect` with the event and its on-screen
position so your app can open a detail card.

[Events on the timeline](/docs/guides/timeline-events) builds that card in
TypeScript and React, with a live demo.

```ts
import { addEventTags } from '@lightfin/core/event-tags'

const tags = addEventTags(chart, {
  events: [
    {
      time: 1700000000,
      symbol: 'E',
      title: 'Q3 earnings',
      body: 'EPS 1.24 vs 1.10 est.',
    },
    {
      time: 1701200000,
      symbol: 'D',
      symbolColor: '#26a69a',
      title: 'Dividend',
      body: '$0.24 / share',
    },
  ],
  onSelect: (event, pos) => openCard(event, pos.clientPoint),
})

tags.setEvents(next) // replace the whole set; the tags repaint
tags.remove()
```

Tags that would overlap stack upward into rows. Hovering a tag replaces the
vertical crosshair with a dotted guide in the tag's color.
The guide stays visible while the associated `card` is open.

## `ChartEvent`

| Field         | Type           | Notes                                                  |
| ------------- | -------------- | ------------------------------------------------------ |
| `time`        | `UTCTimestamp` | Unix seconds UTC, matched to the nearest bar. Required. |
| `symbol`      | `string`       | Bold white text in the tag. Defaults to a bullet.      |
| `symbolColor` | `string`       | Tag fill and hover guide color. Defaults to `lineColor`. |
| `title`       | `string`       | Heading for your popover.                              |
| `body`        | `string`       | Body text for your popover.                            |
| `data`        | `unknown`      | Any payload, handed back untouched on select.          |

## `EventTagsOptions` & handle

`addEventTags(chart, { events, onSelect?, card?, onDismiss? })` returns an `EventTags` handle:

- `setEvents(events)` — replace the whole set; the tags repaint.
- `remove()` — remove the tags and the card's dismiss listeners.

`card` is the detail element. While it is showing, an outside click or Escape sets `hidden`. `onDismiss` runs at the same time, which is how a React card clears its state.

`onSelect(event, pos)` fires on click/tap. `pos` is an `EventTagPosition` with
the tag's top-center anchor in two coordinate spaces:

- `pos.point` — CSS px relative to the chart element.
- `pos.clientPoint` — client (viewport) px, for a `position: fixed` card.

The walkthrough with a live demo is [Events on the timeline](/docs/guides/timeline-events).

```ts
addEventTags(chart, {
  events,
  card,
  onSelect: (event, pos) => {
    card.style.left = `${pos.point.x}px`
    card.style.top = `${pos.point.y}px`
    card.textContent = event.body ?? ''
    card.hidden = false
  },
})
```
