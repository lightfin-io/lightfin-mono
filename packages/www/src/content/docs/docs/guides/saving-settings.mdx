`createAnnotations()` saves drawings to `localStorage` by default.
`createChrome()` uses the same browser storage for the interval, chart type,
and crosshair mode. Each uses its own key, scoped to the page path and chart
container. Give each chart container a stable `id` so it keeps its saved state
when it moves within the page. Use explicit keys to share state across pages.

For a symbol-specific chart, call `chart.setInstrument()` before creating
annotations. The default drawing key uses the exchange and symbol at that
point. When reusing a chart for a different instrument, set the new instrument
and remount annotations to load its drawing list. Remount any chrome that was
attached to the previous annotations instance.

## Restore settings and load bars

Create your price series before mounting chrome and include the available
intervals in `intervals`. With the default adapter, `chrome.interval()`
already reflects the restored value when `createChrome()` returns. If Chrome
restores a different interval, it calls `onIntervalChange` after mounting.
If the interval stays at its initial value, load those bars yourself.

```ts
import { createChart } from '@lightfin/core'
import type { DataSource } from '@lightfin/core'
import { createAnnotations } from '@lightfin/core/annotations'
import { createChrome } from '@lightfin/core/chrome'

function mountChart(
  container: HTMLElement,
  sourceFor: (interval: string) => DataSource,
) {
  const chart = createChart(container, { volumeVisible: true })
  chart.addCandlestickSeries()
  const drawings = createAnnotations(chart)
  const initialInterval = '1H'
  const loadBars = (interval: string) => {
    chart.setDataSource(sourceFor(interval))
  }
  const chrome = createChrome(chart, {
    annotations: drawings,
    intervals: ['5m', '15m', '1H', '1D'],
    interval: initialInterval,
    onIntervalChange: loadBars,
  })
  if (chrome.interval() === initialInterval) loadBars(initialInterval)

  return () => {
    chrome.dispose()
    drawings.dispose()
    chart.remove()
  }
}
```

Your app supplies `sourceFor` to create a [data source](/docs/guides/live-data)
for the selected interval. If your app switches intervals itself, load the
bars and call `chrome.setInterval(interval)` to update and save the selection.
Drawings keep their time and price anchors when you change the interval.

## Choose a storage backend

Pass `persistenceKey` to `createAnnotations()` or `createChrome()` to choose
its `localStorage` key. Use a different key for drawings and settings.
Pass `{ persistence: false }` to keep the corresponding state in memory.

To use your own storage, pass `{ persistence: adapter }`. Implement
`DrawingPersistence` from `@lightfin/core/annotations` for drawing lists and
`SettingsPersistence` from `@lightfin/core/chrome` for chart settings. Each
adapter has `load()` and `save(value)` methods and may return promises.
`load()` returns `null` when no saved state exists. Settings can be partial.
For drawings, `save()` receives the full list, including `[]` after a clear.
Use `onPersistenceError(error, operation)` to report failed reads or writes.

With asynchronous adapters, run the initial bar-loading check from the example
after `await chrome.ready` so a restored interval takes effect first. Await
`drawings.ready` before enabling drawing tools if users should start from the
saved drawings. These promises cover storage restore. Your data source loads
bars separately.

## Reset settings

In chrome's **Reset settings** dialog, **Reset chart options** restores the
initial interval, chart type, and crosshair mode and saves those values.
Chrome calls `onIntervalChange` if resetting selects a different interval.
Provide `onResetChartOptions` if your app also has preferences to reset.
Construction options such as theme and volume visibility come from your app.
Apply those by recreating the chart or changing its React `key`.

**Reset drawing-tool defaults** clears remembered styles for new drawings and
returns to the cursor. You can also call `chrome.resetDrawingToolDefaults()`.
Use `drawings.clear()` to remove current drawings. That operation is undoable
and triggers autosave.
