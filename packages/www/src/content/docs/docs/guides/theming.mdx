Every color, font, and the up/down palette come from one plain object: the
chart's `theme`. Pass a `Partial<ChartTheme>` at creation and it's merged over
`DEFAULT_THEME`, so you only set what you want to change:

```ts
import { createChart } from '@lightfin/core'

const chart = createChart(container, {
  theme: {
    upColor: '#2e7d32',
    downColor: '#c62828',
    lineColor: '#5c6bc0',
  },
})
```

The engine has no live option setter — to change the theme after creation,
re-create the chart with the new `theme`.

Colors accept any CSS color string the canvas understands — `#rgb`, `#rrggbb`,
`rgb()`/`rgba()`. The `volume*` and `area*` defaults are intentionally
semi-transparent so the candles and gridlines read through them.

## A light theme

Set the chart, toolbar, and panel colors together for a light theme.
`colorScheme` controls native browser controls, such as range sliders.

```ts
createChart(container, {
  theme: {
    background: '#ffffff',
    gridColor: '#f0f3fa',
    axisTextColor: '#50545e',
    axisBorderColor: '#e0e3eb',
    crosshairColor: '#9598a1',
    strongTextColor: '#131722',
    buttonHoverBg: 'rgba(80, 84, 94, 0.16)',
    hudHoverBg: 'rgba(255, 255, 255, 0.7)',
    panelBg: '#ebebeb',
    panelTextColor: '#131722',
    panelMutedTextColor: '#50545e',
    panelBorderColor: '#d7d7d7',
    panelHoverBg: 'rgba(80, 84, 94, 0.16)',
    panelInputBg: '#ffffff',
    scrollbarThumbColor: '#8f8f8f',
    scrollbarTrackColor: '#dedede',
    colorScheme: 'light',
  },
})
```

## The chrome follows the theme

The [chrome](/docs/api/chrome) copies the theme values it uses to CSS custom
properties on the host element. Each name is `--lf-` followed by the exact
theme property name, including its capitalization. For example, `lineColor`
becomes `--lf-lineColor`, and `hudHoverBg` becomes `--lf-hudHoverBg`.

On the chrome, a `Bg` name is a fill, a `TextColor` name is text, and a
`BorderColor` name is a border or divider. `strongTextColor`, `buttonHoverBg`,
and `hudHoverBg` paint the toolbars and the HUD. Menus, dialogs, and the
drawing toolbar are panels, with `panelBg`, `panelTextColor`,
`panelMutedTextColor`, `panelBorderColor`, `panelHoverBg`, and
`panelInputBg`. Scrollbars use `scrollbarThumbColor` for the thumb and
`scrollbarTrackColor` for the track.
The host sets `scrollbar-color` (it inherits) and a thin `scrollbar-width`
on itself and everything inside it, so every scrollbar picks them up.
Toolbars keep their scrollbars hidden.

Set the toolbar colors and the panel colors together when the chart
background changes.

## Indicator colors

`indicatorPalette` is handed out round-robin as you add indicators, so a fresh
chart's indicators are distinct without any per-indicator config. An explicit
color in an indicator's options always wins — see
[Indicators → Colors](/docs/api/indicators#colors).
