## Install

The core has no runtime dependencies.

<Tabs>
  <TabItem label="npm">
    ```
    npm i @lightfin/core
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```
    pnpm add @lightfin/core
    ```
  </TabItem>
  <TabItem label="bun">
    ```
    bun add @lightfin/core
    ```
  </TabItem>
</Tabs>

Using React? Add the bindings — `@lightfin/core` and `react` are peer
dependencies:

<Tabs>
  <TabItem label="npm">
    ```
    npm i @lightfin/react
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```
    pnpm add @lightfin/react
    ```
  </TabItem>
  <TabItem label="bun">
    ```
    bun add @lightfin/react
    ```
  </TabItem>
</Tabs>

## Render a chart

```ts
import { createChart } from '@lightfin/core'

const chart = createChart(document.querySelector('#chart')!, {
  volumeVisible: true,
})

chart.addCandlestickSeries().setData(bars)
```

The container should have a size — the chart fills it and watches for resizes.

## Subpath exports

Pay only for what you import. The extras live behind their own entry points so
they tree-shake out when unused:

| Import                           | What it adds                           |
| -------------------------------- | -------------------------------------- |
| `@lightfin/core`                 | Chart engine, series, axes, crosshair  |
| `@lightfin/core/indicators/*`    | One indicator each, loaded on demand   |
| `@lightfin/core/annotations`     | The [21 drawing tools](/docs/api/annotations) |
| `@lightfin/core/annotations/schema` | JSON Schema to let an AI draw        |
| `@lightfin/core/chrome`          | [HUD, legend, toolbars, clock](/docs/api/chrome) |
| `@lightfin/core/price-lines`     | [Order and position price lines](/docs/api/price-lines) |
| `@lightfin/core/event-tags`      | [Earnings / dividend tags](/docs/api/event-tags) |

Indicators are imported one subpath at a time (usually via a dynamic `import()`,
so only the ones you use ship) — see the [Indicators reference](/docs/api/indicators).
